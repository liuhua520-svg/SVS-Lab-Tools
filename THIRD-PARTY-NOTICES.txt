2. How this project uses third-party software

SVS Lab Tools runs as four separate Python processes, each with its own
dependency set, to avoid version conflicts between packages that pin
incompatible transitive dependencies (see the comments at the top of each
requirements file for details):

- Main backend (backend/requirements.txt)       -> app.py, port 5000
- Qwen3-ASR / Qwen3-ForcedAligner (backend/requirements-qwen3.txt)
                                                 -> qwen3_server.py, port 5001
- NVIDIA NeMo Forced Aligner (backend/requirements-nemo.txt)
                                                 -> nemo_server.py, port 5002
- Qwen3-TTS (backend/requirements-qwen3tts.txt) -> qwen3tts_server.py, port 5003

The three optional service environments (Qwen3-ASR/FA, NeMo, Qwen3-TTS) are
only required if the corresponding feature is enabled; a package listed
under one of them is not necessarily installed in every deployment.

  SAPI5 voices used through the "Narrator (Windows)" engine, are cloud/OS

Unless explicitly bundled with this project's own release artifacts,
these resources are downloaded on demand from their official sources at
