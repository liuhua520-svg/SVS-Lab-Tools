# NOTE: whisperx is intentionally NOT installed here (removed — this is the
# other half of the 2026-08 architecture swap described below). WhisperX now
# runs exclusively inside the separate whisperx_server.py process
# (.whisperx_env, see requirements-whisperx.txt) and is called over HTTP on
# 127.0.0.1:5854 — alt_aligners.py's WhisperXAligner class is a thin HTTP

# whisperx/faster-whisper/ctranslate2 installed.

# Both packages have historically never relaxed these pins, so no amount of
# pip backtracking could satisfy both inside one environment at once.
