# SVS Lab Tools

**싱잉 보이스 합성 실험실 도구**

싱잉 보이스 합성(SVS) 워크플로를 위한 독립형 웹 애플리케이션입니다. ‘입력 오디오 + 텍스트’를 싱잉 보이스 합성 소프트웨어에서 사용할 수 있는 프로젝트 파일로 변환합니다.

이 도구의 목적은 SVS를 직접 수행하거나 싱잉 보이스 합성 엔진 자체를 대체하는 것이 아닙니다. 보이스뱅크가 ‘말을 잘하는 척’할 수 있도록 돕는 연결 다리 역할을 합니다.

- 먼저 **[Qwen3-FA](https://github.com/QwenLM/Qwen3-ASR)** 를 사용해 오디오와 텍스트를 자동 정렬하고 `.lab` 파일을 생성합니다.
- 다음으로 **[PyWORLD](https://github.com/JeremyCCHsu/Python-Wrapper-for-World-Vocoder)** 를 사용해 F0 피치 데이터를 추출합니다.
- 마지막으로 싱잉 보이스 합성 프로젝트 파일을 내보내, 해당 소프트웨어에서 추가로 편집하고 재생할 수 있도록 합니다.

## ✨ 주요 기능

* **주석 생성만 수행 (빠른 모드)**  
  Qwen3-FA 자동 정렬만 실행하여 `.lab` 파일을 빠르게 생성합니다.

* **전체 처리 (주석 생성 + F0 + 프로젝트 파일)**  
  주석 생성과 피치 추출을 자동으로 수행한 뒤 싱잉 보이스 합성 프로젝트 파일을 출력합니다.

* **프로젝트 생성만 수행 (WAV + LAB)**  
  기존 `WAV + LAB/MIDI` 를 바탕으로 주석 생성 과정을 다시 수행하지 않고 프로젝트 파일을 바로 생성합니다.

* **다양한 피치 추출 알고리즘 지원**  
  **PyWORLD, CREPE, RMVPE** 세 가지 F0 추출 방식을 제공하며, 필요에 따라 선택할 수 있습니다.

* **연속 피치 데이터 기록 지원**  
  깔끔한 개별 음표만 생성하거나, 연속 F0 곡선을 프로젝트에 기록하여 보다 자연스러운 피치 변화를 보존할 수 있습니다.

* **긴 오디오 처리 지원**  
  긴 오디오 파일도 처리할 수 있어 전체 곡이나 장시간 음성 등의 작업에 적합합니다.

* **다양한 텍스트 변환 방식 지원**  
  ‘프로젝트 생성만 수행 (WAV + LAB/MIDI)’ 모드에서 다음 중 선택할 수 있습니다.

  * 변환 안 함
  * 자음 병합
  * 히라가나
  * 가타카나

* **다양한 오디오 형식 지원**  
  `WAV / MP3 / FLAC / M4A / AAC / OGG`

* **다국어 텍스트 정렬 지원**

* **LAB 파일 내보내기 지원**

* **다양한 정렬 알고리즘 지원**  
  **Montreal Forced Aligner, WhisperX, Qwen3-ASR-1.7B, Qwen3-ForcedAligner-0.6B, NeMo Forced Aligner** 등 다섯 가지 정렬 방식을 제공하며, 필요에 따라 선택할 수 있습니다.

* **간결하고 사용하기 쉬운 웹 인터페이스**

* **일괄 프로젝트 생성 지원**  
  여러 LAB / MIDI / 텍스트 + WAV 입력을 한 번에 프로젝트 파일로 변환할 수 있습니다.

## 📌 활용 사례

- 이미 싱잉 보이스 합성 또는 TTS 오디오가 있고, 빠르게 주석 파일을 생성하려는 경우
- 음성 프로젝트를 싱잉 보이스 합성 소프트웨어로 가져와 추가 편집하려는 경우
- `.lab`, F0 데이터, 프로젝트 파일을 일괄 생성하려는 경우
- ‘말하기’와 ‘노래하기’ 사이에 편집 가능한 중간 단계를 만들려는 경우

## 🛠️ 작동 방식

1. 오디오 파일과 텍스트를 입력합니다.
2. **[Qwen3-FA](https://github.com/QwenLM/Qwen3-ASR)** 로 자동 시간 정렬을 수행합니다.
3. `.lab` 주석 파일을 생성합니다.
4. **[PyWORLD](https://github.com/JeremyCCHsu/Python-Wrapper-for-World-Vocoder)** 로 F0 피치 데이터를 추출합니다.
5. 선택한 처리 모드에 따라 프로젝트 파일을 출력합니다.
6. 결과를 싱잉 보이스 합성 소프트웨어로 가져와 계속 사용합니다.

## 🔧 처리 모드

### 1. 주석 생성만 수행 (빠른 모드)

Qwen3-FA 자동 주석 생성만 수행하여 `.lab` 파일을 만듭니다.

### 2. 전체 처리 (주석 생성 + F0 + 프로젝트 파일)

Qwen3-FA 정렬과 F0 추출을 수행한 다음 프로젝트 파일을 생성합니다.

### 3. 프로젝트 생성만 수행 (WAV + LAB)

기존 WAV + LAB 파일을 사용해 프로젝트 파일을 생성하므로 전체 주석 생성 과정을 다시 수행하지 않아도 됩니다.

### 📋 시스템 요구 사항

- Python 3.8 이상
- Node.js 16 이상
- RAM 4GB
- 사용 가능한 디스크 공간 1GB

## 📖 사용 절차

### 주석 생성만 수행 (빠른 모드)

1. 애플리케이션을 엽니다.
2. 오디오 파일을 업로드합니다.
3. 텍스트를 입력합니다.
4. 언어를 선택합니다.
5. **주석 생성 시작**을 클릭합니다.
6. 생성된 `.lab` 파일을 다운로드합니다.

### 전체 처리 (주석 생성 + F0 + 프로젝트 파일)

1. 오디오 파일을 업로드합니다.
2. 텍스트를 입력합니다.
3. 언어를 선택합니다.
4. 처리 모드를 **전체 처리**로 설정합니다.
5. **처리 시작**을 클릭합니다.
6. 생성된 프로젝트 파일을 다운로드합니다.

### 프로젝트 생성만 수행 (WAV + LAB)

1. WAV 파일과 이에 대응하는 LAB 파일을 준비합니다.
2. **프로젝트 생성만 수행**을 선택합니다.
3. WAV + LAB 파일을 업로드합니다.
4. **생성**을 클릭합니다.
5. 프로젝트 파일을 다운로드합니다.

### 📝 출력 항목

처리 모드에 따라 다음 항목을 출력할 수 있습니다.

- `.lab` 시간 정렬 파일
- F0 피치 데이터
- 싱잉 보이스 합성 프로젝트 파일

### 📌 기능상의 제한

이 도구는 ‘SVS 워크플로 보조 도구’이며 다음 기능은 제공하지 않습니다.

- 싱잉 보이스 합성(SVS) 수행
- 보이스뱅크 모델 학습 또는 수정
- 싱잉 보이스 합성 소프트웨어 대체

---

### 📁 사용자 책임

이 도구가 생성한 결과물(`.lab`, F0 데이터, 프로젝트 파일 포함)의 사용에 대한 책임은 사용자에게 있습니다.

- 결과물을 합법적이고 적절한 목적으로 사용하는지 사용자가 직접 확인해야 합니다.
- 사용하기 전에 오디오와 보이스뱅크의 라이선스 범위를 확인하세요.
- 제3자 보이스뱅크를 사용하는 경우 해당 보이스뱅크의 공식 이용 약관을 준수하세요.

---

### 🎭 보이스뱅크 및 출처 표기 안내

보이스뱅크 또는 합성 시스템에서 출처 표기를 요구하는 경우 해당 조건에 따라 표기하세요. 음성 디렉션에 대한 크레딧이 필요한지는 프로젝트 파일로 변환한 후 보이스뱅크의 음성에서 원본 샘플의 특징이 식별되는지에 따라 달라집니다. 원본 샘플의 특징을 식별할 수 있다면 해당 조건에 따라 출처를 표기하세요. 예시는 다음과 같습니다.

- ‘사용한 보이스뱅크: XXX’
- ‘음성 디렉션: XXX’

---

### 📌 저작권 안내

이 프로젝트는 사용자가 입력한 데이터나 생성된 콘텐츠에 대한 소유권을 주장하지 않습니다.

데이터의 저작권은 사용자에게 있습니다. 다만 원본 샘플을 프로젝트 파일로 변환한 후 사용된 보이스뱅크의 음성에서 원본 샘플의 특징이 식별되는지에 따라 달라질 수 있습니다. 제3자의 원본 샘플 특징이 결과물에서 식별되는 경우, 해당 결과물은 제3자의 2차적 저작물로 간주될 수 있습니다.
