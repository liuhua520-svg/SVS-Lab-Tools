# SVS Lab Tools

**歌声合成ラボツール**

歌声合成（SVS）のワークフロー向けに設計された、完全に独立した Web アプリケーションです。「音声 + テキスト」から、歌声合成ソフトウェアで使用できるプロジェクトファイルを生成します。

本ツールは SVS 自体を行うものでも、歌声合成エンジンそのものを置き換えるものでもありません。歌声ライブラリに「話すのが得意なふり」をさせるための橋渡し役として機能します。

- まず **[Qwen3-FA](https://github.com/QwenLM/Qwen3-ASR)** で音声とテキストを自動アラインメントし、`.lab` ファイルを生成します。
- 次に **[PyWORLD](https://github.com/JeremyCCHsu/Python-Wrapper-for-World-Vocoder)** で F0（基本周波数）のピッチ情報を抽出します。
- 最後に歌声合成用のプロジェクトファイルを出力し、対応ソフトウェアで編集・再生できるようにします。

## ✨ 主な機能

* **アノテーションのみ（高速）**  
  Qwen3-FA による自動アラインメントだけを実行し、`.lab` ファイルをすばやく生成します。

* **フル処理（アノテーション + F0 + プロジェクトファイル）**  
  アノテーションとピッチ抽出を自動で行い、歌声合成用プロジェクトファイルを出力します。

* **プロジェクト生成のみ（WAV + LAB）**  
  既存の `WAV + LAB/MIDI` を使ってプロジェクトファイルを直接生成します。アノテーションをやり直す必要はありません。

* **複数のピッチ抽出アルゴリズムに対応**  
  F0 抽出方式として **PyWORLD、CREPE、RMVPE** の 3 種類を搭載しており、用途に応じて選択できます。

* **連続したピッチデータの書き込みに対応**  
  変化のない音符データのみを生成するか、連続した F0 カーブをプロジェクトに書き込み、より自然なピッチの変化を残すかを選択できます。

* **長時間の音声に対応**  
  長い音声ファイルを処理でき、楽曲全体や長時間の音声などに適しています。

* **複数のテキスト変換方式に対応**  
  「プロジェクト生成のみ（WAV + LAB/MIDI）」モードでは、次の方式を選択できます。

  * 変換しない
  * 子音を結合
  * ひらがな
  * カタカナ

* **複数の音声形式に対応**  
  `WAV / MP3 / FLAC / M4A / AAC / OGG`

* **多言語のテキストアラインメントに対応**

* **LAB ファイルのエクスポートに対応**

* **複数のアラインメントアルゴリズムに対応**  
  **Montreal Forced Aligner、WhisperX、Qwen3-ASR-1.7B、Qwen3-ForcedAligner-0.6B、NeMo Forced Aligner** の 5 種類を搭載しており、用途に応じて選択できます。

* **シンプルで使いやすい Web インターフェース**

* **バッチ処理に対応**  
  複数の LAB / MIDI / テキスト + WAV をまとめてプロジェクトファイルに変換できます。

## 📌 想定される用途

- 歌声合成または TTS の音声がすでにあり、すばやくアノテーションを生成したい
- 音声プロジェクトを歌声合成ソフトウェアに読み込み、さらに編集したい
- `.lab`、F0 データ、プロジェクトファイルを一括生成したい
- 「話す」と「歌う」の間に、編集可能な中間レイヤーを作りたい

---

## 🛠️ 仕組み

1. 音声ファイルとテキストを入力します。
2. **[Qwen3-FA](https://github.com/QwenLM/Qwen3-ASR)** で自動タイムアラインメントを行います。
3. `.lab` アノテーションファイルを生成します。
4. **[PyWORLD](https://github.com/JeremyCCHsu/Python-Wrapper-for-World-Vocoder)** で F0 のピッチ情報を抽出します。
5. 選択した処理モードに応じてプロジェクトファイルを出力します。
6. 生成結果を歌声合成ソフトウェアに読み込み、引き続き使用します。

## 🔧 処理モード

### 1. アノテーションのみ（高速）

Qwen3-FA による自動アノテーションのみを実行し、`.lab` ファイルを生成します。

### 2. フル処理（アノテーション + F0 + プロジェクトファイル）

Qwen3-FA によるアラインメントと F0 抽出を実行し、プロジェクトファイルを生成します。

### 3. プロジェクト生成のみ（WAV + LAB）

既存の WAV + LAB からプロジェクトファイルを生成します。アノテーションの全工程を繰り返す必要はありません。

### 📋 システム要件

- Python 3.8 以降
- Node.js 16 以降
- RAM 4 GB
- 空きディスク容量 1 GB

## 📖 使用手順

### アノテーションのみ（高速）

1. アプリケーションを開きます。
2. 音声ファイルをアップロードします。
3. テキストを入力します。
4. 言語を選択します。
5. **「アノテーション開始」** をクリックします。
6. 生成された `.lab` ファイルをダウンロードします。

### フル処理（アノテーション + F0 + プロジェクトファイル）

1. 音声ファイルをアップロードします。
2. テキストを入力します。
3. 言語を選択します。
4. 処理モードで **「フル処理」** を選択します。
5. **「処理開始」** をクリックします。
6. 生成されたプロジェクトファイルをダウンロードします。

### プロジェクト生成のみ（WAV + LAB）

1. WAV ファイルと対応する LAB ファイルを用意します。
2. **「プロジェクト生成のみ」** を選択します。
3. WAV + LAB ファイルをアップロードします。
4. **「生成」** をクリックします。
5. プロジェクトファイルをダウンロードします。

### 📝 出力内容

処理モードに応じて、次のファイルやデータを出力できます。

- `.lab` タイムアラインメントファイル
- F0 ピッチ情報
- 歌声合成用プロジェクトファイル
